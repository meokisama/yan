# Progress

A candy-cane progress bar. The stripes scroll while it works, the fill overshoots
a little as it grows, and it throws a small party when it reaches 100%.

<ComponentPreview name="progress-demo" />

## Installation

<InstallCommand item="progress" />

## Usage

```tsx
import { Progress } from "@/components/ui/progress"
```

```tsx
<Progress value={60} aria-label="Upload" />
```

## Accessibility

- Built on Radix Progress: `role="progressbar"` with `aria-valuenow` kept in sync.
- Give it an `aria-label` describing what is loading.
- With `prefers-reduced-motion: reduce`, the stripes stop, the width changes instantly and the party is skipped.
