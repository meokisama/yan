# Progress

A candy-cane progress bar with a tiny mochi riding the front of it. Each step
forward it rolls and kicks up clouds. At 100% it jumps for joy in a ring of
emphasis lines.

<ComponentPreview name="progress-demo" />

<InstallCommand item="progress" />

## Usage

```tsx
import { Progress } from "@/components/ui/progress"
```

```tsx
<Progress value={60} aria-label="Upload" />
```

## Accessibility

- Built on Radix Progress: `role="progressbar"` with `aria-valuenow` kept in sync.
- Give it an `aria-label` describing what is loading.
- The rider is decorative and `aria-hidden`. With `prefers-reduced-motion: reduce`, the stripes stop, the width changes instantly and the rolling, clouds and party are skipped.
