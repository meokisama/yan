# Switch

A switch whose thumb is a tiny mochi. Flip it and the mochi smears across the
track, slams into the far end with a splash and wakes up with a ！. Flip it
back and it dozes off with a little Zzz. The colour floods out from under it.

## Usage

```tsx
import { Switch } from "@/components/ui/switch"
```

```tsx
<Switch defaultChecked aria-label="Sparkles" />
```

## Accessibility

- Built on Radix Switch: it renders a `<button role="switch">` and toggles with Space or Enter.
- Wrap it in a `<label>` or pass `aria-label`; the mochi face is decorative and hidden from assistive tech.
- With `prefers-reduced-motion: reduce`, the smear, splash and emote are skipped.
