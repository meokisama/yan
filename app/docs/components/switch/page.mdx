# Switch

A switch whose thumb is a tiny mochi. It naps while the switch is off, wakes up
with a bounce when you turn it on, and pops a few hearts on the way.

<ComponentPreview name="switch-demo" />

## Installation

<InstallCommand item="switch" />

## Usage

```tsx
import { Switch } from "@/components/ui/switch"
```

```tsx
<Switch defaultChecked aria-label="Sparkles" />
```

## Accessibility

- Built on Radix Switch: it renders a `<button role="switch">` and toggles with Space or Enter.
- Wrap it in a `<label>` or pass `aria-label`; the mochi face is decorative and hidden from assistive tech.
- With `prefers-reduced-motion: reduce`, the burst is skipped.
