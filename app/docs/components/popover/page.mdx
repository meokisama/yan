# Popover

A speech bubble with a candy tail. It lands like jelly out of whatever opened
it, with two puffs where it sprang from and a spray of stars off the corner
where its own star keeps twinkling. Close it and it leaves in a cloud. ぽんっ

## Usage

```tsx
import { Popover, PopoverContent, PopoverTrigger } from "@/components/ui/popover"
```

```tsx
<Popover>
  <PopoverTrigger asChild>
    <Button>Open</Button>
  </PopoverTrigger>
  <PopoverContent>Anything can go in here.</PopoverContent>
</Popover>
```

`PopoverClose` closes it from inside, and `PopoverAnchor` positions it against
something other than the trigger. For other bursts, pass a recipe from
[Effects](/docs/effects): `<PopoverContent fx={fxRecipes.bubbles}>`.

## Accessibility

- Built on Radix Popover: focus moves into the card when it opens and returns to the trigger on Escape or an outside click.
- On a phone the card is never wider than the screen minus a 16px margin on each side.
- With `prefers-reduced-motion: reduce`, the card appears without the bounce or the particles.
