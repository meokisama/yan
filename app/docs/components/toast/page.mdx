# Toast

Toasts that bounce in from the corner with a candy mark, a few sparkles and an
onomatopoeia sticker. Call `toast()` from anywhere.

<ComponentPreview name="toast-demo" />

## Installation

<InstallCommand item="toast" />

## Usage

```tsx
// app/layout.tsx: mount it once
import { Toaster } from "@/components/ui/toast"

<Toaster />
```

```tsx
import { toast } from "@/components/ui/toast"

toast("Mochi-chan says hi")
toast.success("Saved!", { description: "Your snack list is safe." })
toast.error("Oh no", { description: "The parfait fell over." })
```

`toast()` returns an id you can pass to `toast.dismiss(id)`. At most four toasts are shown at once.

## Accessibility

- Built on Radix Toast: toasts are announced by screen readers, pause on hover and focus, and can be swiped away.
- Press F8 to move focus to the toast region.
- With `prefers-reduced-motion: reduce`, toasts appear without the bounce, the sparkles or the sticker.
