# Tooltip

A little speech bubble that pops out of whatever it describes, with a bounce,
two tiny puffs and a glint.

<ComponentPreview name="tooltip-demo" />

## Installation

<InstallCommand item="tooltip" />

## Usage

```tsx
import { Tooltip, TooltipContent, TooltipTrigger } from "@/components/ui/tooltip"
```

```tsx
<Tooltip>
  <TooltipTrigger>Hover me</TooltipTrigger>
  <TooltipContent>ぽんっ!</TooltipContent>
</Tooltip>
```

Each `Tooltip` brings its own provider. To share one delay across many tooltips,
wrap them in `TooltipProvider` yourself.

## Accessibility

- Built on Radix Tooltip: it opens on hover and on keyboard focus, and closes with Escape.
- A tooltip is a hint, not a label. Icon-only buttons still need `aria-label`.
- With `prefers-reduced-motion: reduce`, the bubble appears without the bounce or the puffs.
