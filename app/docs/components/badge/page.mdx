# Badge

A sticker-style label with a candy fill, a white die-cut outline and a tiny edge
shadow. Six flavours and an outline.

<ComponentPreview name="badge-demo" />

## Installation

<InstallCommand item="badge" />

## Usage

```tsx
import { Badge } from "@/components/ui/badge"
```

```tsx
<Badge color="mint">Fresh</Badge>
```

Add `dot` for a twinkling status dot, or `asChild` to make a link look like a badge:

```tsx
<Badge dot>New</Badge>

<Badge asChild color="sky">
  <a href="/changelog">v0.2</a>
</Badge>
```

## Accessibility

- It renders a plain `<span>`, so it is read inline with the surrounding text.
- The twinkling dot is `aria-hidden` and stops with `prefers-reduced-motion: reduce`.
- Color is never the only signal: keep the label text meaningful.
