# Dropdown Menu

A puffy menu that lands like jelly and deals its items in one by one. The
highlight is a gummy candy that stretches from item to item as you move, and
turns coral over a destructive one. Pick an item and it throws sparkles and
hearts on its way out. ぷにっ

## Usage

```tsx
import {
  DropdownMenu,
  DropdownMenuContent,
  DropdownMenuItem,
  DropdownMenuTrigger,
} from "@/components/ui/dropdown-menu"
```

```tsx
<DropdownMenu>
  <DropdownMenuTrigger asChild>
    <Button>Open</Button>
  </DropdownMenuTrigger>
  <DropdownMenuContent>
    <DropdownMenuItem>Add to box</DropdownMenuItem>
    <DropdownMenuItem variant="destructive">Empty the box</DropdownMenuItem>
  </DropdownMenuContent>
</DropdownMenu>
```

Also exported: `DropdownMenuLabel`, `DropdownMenuSeparator`, `DropdownMenuShortcut`,
`DropdownMenuGroup`, `DropdownMenuCheckboxItem`, `DropdownMenuRadioGroup`, `DropdownMenuRadioItem`,
`DropdownMenuSub`, `DropdownMenuSubTrigger` and `DropdownMenuSubContent`.

For other bursts, pass a recipe from [Effects](/docs/effects):
`<DropdownMenuContent fx={fxRecipes.stars}>`.

## Accessibility

- Built on Radix Dropdown Menu: arrow keys, typeahead, Home/End and Escape all work, and focus returns to the trigger.
- Checkbox and radio items announce their state. The heart is decoration.
- With `prefers-reduced-motion: reduce`, the menu appears at once, the highlight jumps instead of stretching, and no particles are drawn.
