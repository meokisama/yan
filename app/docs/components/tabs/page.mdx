# Tabs

A tray of tabs where the active one is a gummy candy. It pops when you pick it
and the panel floats up into place.

<ComponentPreview name="tabs-demo" />

## Installation

<InstallCommand item="tabs" />

## Usage

```tsx
import { Tabs, TabsContent, TabsList, TabsTrigger } from "@/components/ui/tabs"
```

```tsx
<Tabs defaultValue="sweet">
  <TabsList>
    <TabsTrigger value="sweet">Sweet</TabsTrigger>
    <TabsTrigger value="sour">Sour</TabsTrigger>
  </TabsList>
  <TabsContent value="sweet">Strawberry daifuku.</TabsContent>
  <TabsContent value="sour">Lemon drops.</TabsContent>
</Tabs>
```

## Accessibility

- Built on Radix Tabs: arrow keys move between tabs, Home and End jump to the ends, and panels are linked with `aria-controls`.
- The sparkle burst only fires for pointer presses; keyboard users get the pop animation.
- With `prefers-reduced-motion: reduce`, the pop, the sparkles and the panel float are skipped.
