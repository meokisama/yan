# Button

A mochi-squishy button. It squashes when pressed, wobbles back like jelly, and
pops sparkles, hearts and a little onomatopoeia when clicked.

<ComponentPreview name="button-demo" />

## Installation

<InstallCommand item="button" />

## Usage

```tsx
import { Button } from "@/components/ui/button"
```

```tsx
<Button>おはよう！</Button>
```

### Variants

<ComponentPreview name="button-variants" />

### Intensity

`kawaii` is the default. Use `subtle` where you want a lighter touch, or `off`
for a plain button. Set your own sticker with `sfx`, or hide it with `sfx={false}`.

<ComponentPreview name="button-intensity" />

### Sizes & custom effects

Pass `fx` to change the burst: shapes, colors, count and power.

<ComponentPreview name="button-sizes" />

### As a link

Use `asChild` to give another element (such as Next.js `Link`) the button's
look and behavior.

```tsx
<Button asChild>
  <Link href="/docs">Get started</Link>
</Button>
```

## Accessibility

- It renders a native `<button>`, so focus, Enter and Space work as usual. Keyboard clicks burst from the button's center.
- The effects canvas is `aria-hidden` and ignores the pointer.
- With `prefers-reduced-motion: reduce`, squish and particles are skipped.
