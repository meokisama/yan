# Select

A raised pill trigger that presses down while its puffy menu is open. Pick an
option and a heart flies from it back to the trigger, which wobbles as it lands.

<ComponentPreview name="select-demo" />

## Installation

<InstallCommand item="select" />

## Usage

```tsx
import {
  Select,
  SelectContent,
  SelectItem,
  SelectTrigger,
  SelectValue,
} from "@/components/ui/select"
```

```tsx
<Select>
  <SelectTrigger className="w-56">
    <SelectValue placeholder="Pick a flavour" />
  </SelectTrigger>
  <SelectContent>
    <SelectItem value="sakura">Sakura</SelectItem>
    <SelectItem value="matcha">Matcha</SelectItem>
  </SelectContent>
</Select>
```

Group options with `SelectGroup`, `SelectLabel` and `SelectSeparator`, as in the demo above.

## Accessibility

- Built on Radix Select: arrow keys, typeahead, Home/End and Escape all work, and focus returns to the trigger.
- Give the trigger an `aria-label` when there is no visible label.
- With `prefers-reduced-motion: reduce`, the menu appears without the bounce and no heart flies.
