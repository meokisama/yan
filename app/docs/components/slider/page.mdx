# Slider

A candy-filled slider. The heart thumb grows when you grab it and leaves a trail
of sparkles as it moves.

<ComponentPreview name="slider-demo" />

## Installation

<InstallCommand item="slider" />

## Usage

```tsx
import { Slider } from "@/components/ui/slider"
```

```tsx
<Slider defaultValue={[64]} max={100} step={1} aria-label="Moe level" />
```

Pass two values for a range:

```tsx
<Slider defaultValue={[20, 80]} />
```

## Accessibility

- Built on Radix Slider: arrow keys, Page Up/Down, Home and End all work, and each thumb is a `role="slider"`.
- Give it an `aria-label` or `aria-labelledby`.
- The sparkle trail is throttled and skipped entirely with `prefers-reduced-motion: reduce`.
