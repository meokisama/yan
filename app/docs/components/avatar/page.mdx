# Avatar

A sticker-style avatar with a white die-cut ring and a candy edge. When there is
no image, the fallback takes the avatar's flavour. Give it an `emote` and a
manga emotion mark pops off it when the pointer arrives.

<InstallCommand item="avatar" />

## Usage

```tsx
import { Avatar, AvatarFallback, AvatarImage } from "@/components/ui/avatar"
```

```tsx
<Avatar color="mint">
  <AvatarImage src="/mochi-avatar.svg" alt="Mochi-chan" />
  <AvatarFallback>MC</AvatarFallback>
</Avatar>
```

Wrap several in `AvatarGroup` to overlap them into a row; the one under the pointer hops up.

## Accessibility

- Built on Radix Avatar: the fallback shows while the image loads and stays if it fails.
- Give `AvatarImage` a meaningful `alt`, or an empty one when the name is already next to it.
- Fallback initials are plain text, so they are read out. Keep them short.
