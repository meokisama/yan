# Accordion

Each row carries a bud. Open the row and the bud blooms into a sakura, the row
rises onto a candy edge with a jelly wobble, and petals fall into the panel as
it unfolds. Close it and the flower folds back up. ふわっ

## Usage

```tsx
import { Accordion, AccordionContent, AccordionItem, AccordionTrigger } from "@/components/ui/accordion"
```

```tsx
<Accordion type="single" collapsible>
  <AccordionItem value="one">
    <AccordionTrigger>Can I freeze it?</AccordionTrigger>
    <AccordionContent>Yes. Wrap each piece first.</AccordionContent>
  </AccordionItem>
</Accordion>
```

Use `type="multiple"` to let several rows stay open. For other bursts, pass a
recipe from [Effects](/docs/effects): `<Accordion fx={fxRecipes.petals}>`.

## Accessibility

- Built on Radix Accordion: each trigger is a button inside a heading, with arrow keys, Home and End moving between rows.
- The flower is decoration: open and closed are announced through `aria-expanded`.
- With `prefers-reduced-motion: reduce`, panels open without the unfold, the wobble or the petals.
