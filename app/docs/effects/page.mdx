# Effects

Every particle comes from `lib/yan-fx.ts`. Components fire it for you, and the
`fx` prop lets you change what flies out. キラッ

## Recipes

`fxRecipes` are named bursts. Pass one to `fx` on any component that has it.

<ComponentPreview name="fx-recipes" />

```tsx
import { Button } from "@/components/ui/button"
import { fxRecipes } from "@/lib/yan-fx"

<Button fx={fxRecipes.hearts}>Like</Button>
```

A recipe is a plain object, so spread it to adjust one: `fx={{ ...fxRecipes.petals, count: 30 }}`.

## burst()

Call it yourself for a moment no component covers:

```tsx
import { burst } from "@/lib/yan-fx"

// at a point in the viewport…
burst({ x: 200, y: 120 }, { shapes: ["heart"], count: 12, word: "ドキッ" })

// …or at the center of an element
burst(document.querySelector("#save")!, { shapes: ["petal"], count: 20 })
```

## Other effects

`burst()` is one word in the vocabulary. The rest are small, authored effects
that components combine into a beat:

<ComponentPreview name="fx-effects" />

```tsx
import { bloom, emote, fly, impact, puff, speedLines } from "@/lib/yan-fx"

impact(button)                 // soft glow + emphasis lines + clouds off both ends
puff(el, { count: 3 })         // "pofu" clouds, animated on twos
speedLines(el)                 // manga emphasis lines around an element
bloom(checkbox)                // a sakura unfolds around it, then lets its petals go
emote(el, "！")                // an emotion mark popping off a corner
fly(option, trigger)           // a heart that arcs from one element to another
```

Every effect is a no-op under `prefers-reduced-motion: reduce`.
